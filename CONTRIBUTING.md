# Contribuir

Abre una incidencia para proponer un proyecto, mejorar instrucciones o comunicar un fallo. Indica placa y revisión, núcleo, bibliotecas y pasos para reproducirlo. No adjuntes contraseñas, SSID/BSSID reales, datos personales ni volcados de flash.

Para un proyecto nuevo, incluye fuentes, licencia, pines, dependencias y evidencias que separen compilación, autopruebas y pruebas físicas. Cada proyecto debe tener una fuente canónica y una descarga clara. Presenta cambios mediante pull request y respeta la licencia MIT del contenido propio y las licencias de terceros.
