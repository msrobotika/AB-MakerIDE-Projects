# Constitución · AB MakerIDE Projects

## Principios
1. **Procedencia real**: conservar byte a byte los tres archivos de firmware y las referencias aportadas; cambios de documentación identificados.
2. **Evidencia honesta**: separar vídeo físico, declaraciones históricas, compilación actual y tests; una compilación no demuestra LCD ni táctil.
3. **Privacidad**: ocultar SSID/BSSID en fotogramas publicados; no subir vídeo completo, volcados de flash, credenciales, rutas personales ni copias de dispositivo.
4. **Preservación**: respaldo local SHA-256 antes de cambios; no sobrescribir el proyecto original.
5. **Alcance autorizado**: por petición expresa del 2026-10-30, hacer público AB-Displays-Lab y crear AB-MakerIDE-Projects como catálogo público del IDE. Se sustituye la restricción anterior de que solo el IDE sea público. Se permite licencia MIT del contenido propio y ZIP de fuentes revisado. Sin releases, grabación, publicación en TikTok, cambios al IDE ni agentes adicionales.

## Flujo y gobernanza
Aplicar Spec Kit antes de cada mejora: especificación, aclaraciones, plan, tareas, checklist/coherencia, implementación y verificación por criterio. Esta incorporación documenta el proyecto existente, sin rehacer retrospectivamente su desarrollo.
Proceso manual: CLI `specify` no instalada ni disponible en PATH; se usan las cinco plantillas oficiales de la copia local GitHub-Spec-Kit 1.2.3. No se instalan extensiones. La base es el commit inicial vacío local; los seis originales se respaldan fuera del repositorio con hashes.
